# BikeChain — Blockchain & Smart Contract Layer (Phase 3)

This directory is prepared for **Phase 3: Smart Contract & Hardhat**:
- Solidity smart contract: `BikeChain.sol`
- Role-based permissions (`ADMIN_ROLE`, `DEALER_ROLE`, `WORKSHOP_ROLE`)
- State structures:
  - `BikeIdentity`
  - `OwnershipRecord`
  - `ServiceRecord`
  - `PartsRecord`
  - `RepairRecord`
- Comprehensive Hardhat Mocha/Chai test suites
- Deployment scripts targeting local Hardhat network and Ethereum Sepolia testnet
